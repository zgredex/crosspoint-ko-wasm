페이지

?

이미지 픽셀 전용 디더링 모델(사진·표지·삽화) — 텍스트는 이 설정의 영향을 받지 않습니다(텍스트는 안티앨리어싱 스위치 담당). 모델은 내보내기 톤 깊이에 맞춰 적용됩니다: 2-bit XTCH는 4단계, 1-bit XTC는 2단계(이미 디더링된 페이지를 다시 디더링하지 않고 원본 이미지에서 한 번에). 톤 기준은 공식 변환기 epub2xtc.xteink.cn의 모델 그대로입니다 — 단계 0/85/170/255, 컷 42/127/212(경계값은 아래 구간에 포함), 1비트는 128. srokl/xtcjsapp과 x4converter.rho.sh도 같은 값을 씁니다. 그래서 평평한 회색 패치는 자기 값으로 되돌아옵니다(4단계 ±0.42, 2단계 ±1.12). 정렬형: 블루 노이즈(기본, 64×64), 바이어(4×4). 오차 확산: Floyd–Steinberg, Atkinson, Jarvis–Judice–Ninke, Stucki, Burkes, Zhou–Fang(강도별 커널 + 임계값 변조, 여기서는 결정적 — 원본은 Math.random() 사용). 톤 오차(평균 |패치 평균 − 원본 회색|, 0~255 기준) — 4단계: 블루 노이즈 0.21 · FS 0.48 · Burkes 0.80 · ko 포크 해시 1.75 · Atkinson 4.79 · 없음 22.8 / 2단계: 블루 노이즈 0.56 · FS 1.29 · ko 포크 해시 35.2 · 없음 69.6. ko 포크 해시 2비트는 펌웨어 양자화기 그대로라 컷이 단계값(85/170)에 있어 중간톤이 어긋납니다(올바른 컷은 중간점 42/127/212). 1비트는 펌웨어의 quantize1bit를 그대로 씁니다. 1비트 텍스트 하프톤의 잉크 밀도도 같은 모델에서 파생됩니다(단계 L → 잉크 255−L = 0/170/85/255, 즉 0/67%/33%/100%). 미리보기의 네 단계 색은 별개의 표시 문제로, 패널의 실제 반사율(정규화)로 그립니다. 공식 변환기와 아직 다른 점: 공식은 오차 확산에 강도(이미지 75%, 배경 50%)를 걸고 기본이 페이지 전체 디더링이며 미리보기에 단계값을 그대로 칠합니다. 여기서는 100% 확산·이미지만 디더링합니다.
